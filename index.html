Ver glosario de siglas y conceptos

Abreviaturas incluidas en la guía y en los mensajes. Algunas se explican por su función en lugar de desarrollar su nombre completo.

ETD / ETCD — terminal de datos / equipo de comunicación de datos (módem).
bps / baudios — bits por segundo / cambios de señal por segundo.
ASCII — código tradicional de caracteres de 7 bits (128 símbolos).
EBCDIC / Baudot — códigos de caracteres de 8 y 5 bits, respectivamente.
UTF-8 — codificación Unicode de longitud variable.
ASK / FSK / PSK / QAM — modulación por amplitud / frecuencia / fase / amplitud y fase.
CRC / FCS — comprobación de errores / campo de verificación de trama.
ARQ / FEC — retransmisión para corregir errores / corrección directa.
BSC — Binary Synchronous Communications (Bisync), protocolo de IBM orientado a carácter.
ENQ — solicita iniciar el intercambio o pedir la línea en BSC.
ACK0 / ACK1 — acuses de recepción alternados en BSC.
NAK — respuesta negativa; provoca retransmisión del bloque erróneo.
BCC — comprobación de errores del bloque en el diálogo BSC de la guía; no es un protocolo aparte.
EOT — fin de transmisión en BSC.
DLE / STX / ETX — caracteres usados para delimitar el comienzo y fin de texto transparente.
HDLC — protocolo de enlace orientado a bits; bandera 01111110.
SDLC — protocolo de enlace de IBM para SNA; usa modo NRM según la guía.
NRM / ARM / ABM — modos de transmisión de estaciones en HDLC.
LAPB / PLP — enlace y paquete en los niveles 2 y 3 de X.25.
SVC / PVC — circuito virtual conmutado / circuito virtual permanente.
PAN / LAN / MAN / WAN — red personal / local / metropolitana / de área amplia.
P2P — entre pares; los equipos pueden ofrecer y solicitar servicios.
OSI — modelo de referencia de siete capas.
MAC / IP — dirección física de enlace (48 bits en la guía) / dirección lógica de red.
TCP / UDP — protocolos de transporte; TCP es confiable y UDP no garantiza entrega.
HTTP / HTTPS / DNS — web / web segura / resolución de nombres.
ISO / UIT-T / IEEE / IETF — organismos de normalización citados en la guía.

Temas destacados según los mensajes compartidos, no una confirmación oficial del profesor.
